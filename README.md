# Orthera

Downloads and update feed of Orthera, the bimover add-on for Archicad 28 and 29 (macOS and Windows) that colours model elements by how far they deviate from a right angle.

- Product page and licences: https://www.bimover.ch/products/orthera
- Latest version: [Orthera-mac.zip](https://github.com/bimover/Orthera/releases/latest/download/Orthera-mac.zip), [Orthera-windows.zip](https://github.com/bimover/Orthera/releases/latest/download/Orthera-windows.zip)
- Update feed: `appcast.xml` (read via https://www.bimover.ch/updates/orthera/appcast.xml)

The source code is not public.
